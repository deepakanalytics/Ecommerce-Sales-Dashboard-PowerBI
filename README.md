# E-Commerce Sales Dashboard (Power BI)

## Project Overview

This Power BI dashboard provides an interactive analysis of e-commerce sales performance. The dashboard helps track revenue, profit, customer behavior, product category performance, and payment trends to support business decision-making.

## Tools Used

- Power BI
- Excel
- DAX
- Data Modeling

## Key Metrics

| KPI | Value |
|------|------|
| Total Sales Amount | 438K |
| Total Quantity Sold | 6K |
| Total Profit | 37K |
| Average Order Value (AOV) | 121K |

## Dashboard Features

- State-wise Sales Analysis
- Category-wise Quantity Analysis
- Monthly Profit Trend Analysis
- Customer Performance Analysis
- Payment Mode Distribution
- Sub-Category Profit Analysis
- Quarter and State Filters

## Key Insights

- Maharashtra generated the highest sales revenue among all states.
- Clothing category contributed the highest share of total quantity sold.
- COD was the most preferred payment method.
- Printers and Bookcases were the most profitable sub-categories.
- November recorded the highest monthly profit.
